Utility for collecting information about spam mail.

# Setup

```
git clone https://github.com/LeipzigeSports/les-spam.git
cd les-spam
python3 -m venv .venv
source .venv/bin/activate
python -m pip install requirements.txt
cp .env.example .env
```

Set mail account credentials in `.env` file.
Run application using `python main.py`.
